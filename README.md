# 📅 Nobatyar \| نوبتیار

## 🏪 سیستم مدیریت نوبت‌دهی خدمات

**نوبتیار** یک برنامه دسکتاپ فارسی برای مدیریت نوبت‌های مشتریان و
سامان‌دهی خدمات، کارمندان و شیفت‌های کاری است. این برنامه با هدف ساده‌سازی
فرایند نوبت‌دهی، نمایش زمان‌های آزاد و جلوگیری از تداخل نوبت‌ها طراحی شده
است.

`<a id="architecture">`{=html}`</a>`{=html} \## 🏗️ معماری پروژه

ساختار پروژه به‌صورت ماژولار طراحی شده است تا رابط کاربری، کنترل
درخواست‌ها، منطق برنامه و دسترسی به داده‌ها از یکدیگر جدا باشند.

``` text
View
لایه رابط کاربری
       ↓
Controller
مدیریت درخواست‌ها و هماهنگی میان بخش‌ها
       ↓
Business Logic
اجرای قوانین و منطق نوبت‌دهی
       ↓
Data Access
دسترسی و مدیریت داده‌ها
```

### مسئولیت هر لایه

-   **Model:** تعریف مدل‌ها و ساختار اطلاعاتی برنامه
-   **Data Access:** مدیریت عملیات خواندن و نوشتن داده‌ها
-   **Business Logic:** اجرای قوانین نوبت‌دهی و بررسی شرایط ثبت نوبت
-   **Controller:** هماهنگی میان رابط کاربری و منطق برنامه
-   **View:** نمایش اطلاعات و دریافت ورودی از کاربر
-   **Tools:** ابزارها و توابع کمکی
-   **Test:** نگهداری تست‌های پروژه

`<a id="installation">`{=html}`</a>`{=html} \## 📦 نصب و راه‌اندازی

### پیش‌نیازها

-   نصب Python
-   دریافت کد پروژه و بازکردن پوشه اصلی آن در محیط توسعه دلخواه

### اجرای برنامه

از ترمینال، وارد پوشه اصلی پروژه شوید و دستور زیر را اجرا کنید:

``` bash
python main.py
```

اگر دستور `python` در محیط شما به نسخه موردنظر اشاره نمی‌کند، می‌توانید از
دستور زیر استفاده کنید:

``` bash
python3 main.py
```

`<a id="usage">`{=html}`</a>`{=html} \## 🚀 نحوه استفاده

پس از اجرای برنامه، بخش موردنظر را برای مدیریت اطلاعات انتخاب کنید:

1.  **مشتریان:** ثبت، ویرایش، حذف یا جست‌وجوی مشتری بر اساس شماره موبایل
2.  **کارمندان:** مدیریت اطلاعات کارمندان و مشاهده شیفت‌های کاری
3.  **خدمات:** تعریف خدمات و مشخص‌کردن قیمت و مدت‌زمان هر خدمت
4.  **شیفت‌ها:** تنظیم روز و ساعت کاری و اتصال کارمند به خدمت
5.  **نوبت‌ها:** ثبت و ویرایش نوبت، مشاهده ساعت‌های آزاد و لغو نوبت

هنگام ثبت نوبت، زمان‌های آزاد باید بررسی شوند تا از هم‌پوشانی نوبت‌ها
جلوگیری شود.

`<a id="project-structure">`{=html}`</a>`{=html} \## 📁 ساختار پروژه

``` text
nobatyar/
├── model/              # مدل‌ها و ساختار اطلاعات
├── data_access/        # دسترسی به داده‌ها
├── business_logic/     # قوانین و منطق نوبت‌دهی
├── controller/         # کنترل درخواست‌ها و هماهنگی بخش‌ها
├── view/               # رابط کاربری
├── tools/              # ابزارها و توابع کمکی
├── test/               # تست‌های پروژه
└── main.py             # نقطه ورود برنامه
```

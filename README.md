# 📅 Nobatyar | نوبتیار

## 🏪 سیستم مدیریت نوبت‌دهی خدمات

نوبتیار یک برنامه دسکتاپ فارسی برای مدیریت نوبت‌های مشتریان است. این برنامه با هدف ساده‌سازی فرآیند ثبت مشتری، مدیریت کارمندان، تعریف خدمات، برنامه‌ریزی شیفت‌ها و ثبت نوبت طراحی شده است.

این سیستم می‌تواند برای مطب‌ها، سالن‌های زیبایی، آرایشگاه‌ها، مراکز مشاوره، کلینیک‌ها، کارگاه‌ها و سایر کسب‌وکارهای خدماتی استفاده شود.

---

## 📌 معرفی پروژه

در بسیاری از کسب‌وکارهای خدماتی، ثبت نوبت به صورت دستی باعث ایجاد مشکلاتی مانند تداخل ساعت‌ها، فراموش شدن نوبت‌ها، اشتباه در قیمت خدمات و دشواری مدیریت کارمندان می‌شود.

نوبتیار برای حل این مشکلات طراحی شده است. مدیر سیستم می‌تواند خدمات مختلف را تعریف کند، برای هر کارمند شیفت کاری تعیین کند و نوبت مشتریان را در ساعت‌های آزاد ثبت کند.

برنامه هنگام ثبت نوبت بررسی می‌کند که:

- ساعت انتخاب‌شده داخل شیفت کارمند باشد.
- خدمت انتخاب‌شده توسط کارمند ارائه شود.
- ساعت موردنظر قبلاً رزرو نشده باشد.
- مدت خدمت با زمان باقی‌مانده شیفت هماهنگ باشد.
- قیمت ثبت‌شده مربوط به همان زمان رزرو باشد.

📦 نصب پروژه
ابتدا پروژه را دریافت کنید:
git clone https://github.com/USERNAME/nobatyar.git

وارد پوشه پروژه شوید:
cd nobatyar

یک محیط مجازی بسازید:
python3 -m venv .venv

فعال‌سازی محیط مجازی در macOS و Linux:
source .venv/bin/activate

فعال‌سازی در Windows:
.venv\Scripts\activate

کتابخانه موردنیاز را نصب کنید:
python -m pip install persiantools

⏱️ مدیریت زمان نوبت‌ها
مدت هر خدمت توسط مدیر تعیین می‌شود.

برای مثال:
جراحی        60 دقیقه
کاشت ناخن    45 دقیقه
ویزیت        30 دقیقه
اگر یک شیفت از ساعت 08:00 تا 10:00 باشد و مشتری اول از ساعت 08:00 تا 09:00 نوبت بگیرد، ساعت 08:00 تا 09:00 برای مشتریان دیگر نمایش داده نمی‌شود.
💰 مدیریت قیمت
قیمت هر خدمت توسط مدیر تعیین می‌شود.

هنگام ثبت نوبت، قیمت همان لحظه در نوبت ذخیره می‌شود.

بنابراین اگر قیمت خدمت بعداً تغییر کند:
- نوبت‌های قبلی قیمت قبلی را حفظ می‌کنند.
- نوبت‌های جدید با قیمت جدید ثبت می‌شوند.
❌ لغو نوبت
با لغو نوبت، نوبت از فهرست نوبت‌های فعال خارج می‌شود و در بخش نوبت‌های لغوشده قرار می‌گیرد.

اطلاعات زیر برای نوبت لغوشده حفظ می‌شود:
- مشتری
- کارمند
- خدمت
- تاریخ
- ساعت
- مبلغ
